_Cloud for interviews — you've built on Lambda, so this is about being able to **articulate** it, not learn it. Guided order first, full note grid below._

## Learn in this order

- [[Lambda]] — cold starts, triggers, Lambda + Spring Boot (your real experience — practice saying it out loud)
- [[Core Services]] — S3, EC2, RDS, SQS: what each is for in one line
- [[IAM]] — roles vs. policies, least privilege
- [[Architecture Patterns]] — when serverless vs. containers vs. EC2

> [!tip] Your edge
> You have 7 years of hands-on AWS. The gap isn't knowledge, it's _framing_. For
> each note, write the "at my last job I used this to…" sentence — that's what
> interviewers actually score.
